# Advanced Cybersecurity Risk Quantification and Control Investment Analysis

## Project Overview
This project presents a cybersecurity risk assessment and financial analysis of SecureBank Financial's SecureMobile Banking Platform. It evaluates identified vulnerabilities, quantifies potential financial exposure, and recommends security investments to reduce organisational risk.

## Key Areas Covered
- Cybersecurity risk identification and quantification.
- Annualized Loss Exposure (ALE) assessment.
- Security control investment and cost analysis.
- Expected risk reduction and Return on Investment (ROI).
- Risk treatment implementation timeline.
- Board-level recommendations and oversight.

## Key Findings

| Metric | Estimated Value |
|---|---:|
| Total Annual Risk Exposure | $35 million |
| Expected Risk Reduction | $26.96 million |
| Projected Residual Exposure | $8.04 million |
| Initial Control Investment | $700,000 |
| Annual Maintenance Cost | $105,000 |
| Expected Risk Reduction | 77.04% |

## Recommended Security Controls
1. Advanced API Security Gateway
2. Web Application Firewall (WAF)
3. Multi-Factor Authentication (MFA) Enhancement

## Deliverables
- Board-level cybersecurity risk briefing.
- Risk exposure and investment analysis.
- First-year ROI comparison.
- Cybersecurity risk treatment Gantt chart.
- Financial justification and recommendations.
